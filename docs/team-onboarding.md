# gov-data 커넥터 사용 안내 (팀원용)

> Claude에서 정부 공공데이터를 바로 조회하는 사내 커넥터입니다. 설치할 프로그램 없이 URL 등록 한 번이면 끝납니다. (소요 2분)

## 무엇을 할 수 있나요

Claude 대화창에 아래처럼 물어보면 실시간 공공데이터로 답합니다.

| 데이터 | 예시 질문 |
|--------|-----------|
| 중기부 지원사업 공고 | "이번 주 중기부 지원사업 공고 알려줘" |
| 정부24 서비스 | "소상공인 대상 정부 지원 서비스 찾아줘" |
| 기업마당 지원사업 | "기업마당에서 수출 관련 지원사업 검색해줘" |
| 나라장터 입찰 | "최근 30일 AI 관련 입찰 공고 보여줘" |
| 중소벤처24 공고 | "마감 안 지난 중소벤처24 공고 정리해줘" |

## 등록 방법 (Claude Desktop)

1. 관리자(레오)에게 **부서 토큰**을 받습니다.
2. Claude Desktop → 설정(⚙) → **커넥터** → **커스텀 커넥터 추가**
3. 아래 입력 후 저장:
   - 이름: `gov-data`
   - URL: `https://port-0-gov-data-mcp-mrvnrogm068d6cba.sel3.cloudtype.app/t/<부서토큰>/mcp`
     (`<부서토큰>` 자리에 받은 토큰을 그대로 붙여넣기)
4. 새 대화를 열고 "중기부 최신 공고 3개 알려줘"로 동작 확인.

claude.ai 웹/모바일도 같은 방법으로 등록됩니다 (설정 → 커넥터).

### 개발자용 (Claude Code)

```bash
claude mcp add gov-data --transport http \
  https://port-0-gov-data-mcp-mrvnrogm068d6cba.sel3.cloudtype.app/mcp \
  --header "Authorization: Bearer <부서토큰>"
```

## 주의사항

- **토큰은 부서 밖으로 공유 금지.** 유출 시 해당 부서 토큰만 회수·재발급됩니다.
- 결과가 "0건"으로 나오면 실제로 공고가 없거나, 일일 호출 한도(전 부서 공용) 소진일 수 있습니다. 한도는 매일 자정(KST) 초기화됩니다.
- 결과는 항목당 500자로 요약됩니다. 상세는 답변에 포함된 원문 링크로 확인하세요.
- 서버가 하루 1회 재시작되어 이른 아침 첫 호출은 몇 초 느릴 수 있습니다.
