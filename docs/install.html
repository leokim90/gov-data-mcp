정부 공공데이터 · MCP

gov-data-mcp 설치 가이드

중기부 사업공고 · 정부24 혜택 · 나라장터 입찰을 Claude에서 자연어로 조회. 아래 3단계만 따라 하세요.

키 1개만 있어도 시작할 수 있어요. DATA_GO_KR_SERVICE_KEY 하나면 중기부·정부24·나라장터 3종이 동작합니다. 나머지 2개는 선택입니다.
1

API 키 발급

각 사이트에서 무료로 발급받습니다. 회원가입 포함 사이트당 약 5~10분.

필수

data.go.kr

DATA_GO_KR_SERVICE_KEY
  1. data.go.kr 회원가입
  2. 마이페이지 → 인증키 발급현황
  3. 일반 인증키(Encoding) 값 복사
  4. 중기부/정부24/나라장터 API 각각 활용신청
선택

기업마당

BIZINFO_API_KEY
  1. bizinfo.go.kr 회원가입
  2. 마이페이지 → 오픈API 신청/관리
  3. 오픈API 신청 → 인증키 복사
선택

중소벤처24

SMES_API_KEY
  1. smes.go.kr 회원가입
  2. 마이페이지 → Open API 관리
  3. API 토큰 신청 → 토큰 복사

⚠️ data.go.kr 키는 첫 발급 후 실제 호출까지 최대 1~2시간 걸릴 수 있어요.

2

클라이언트에 등록

사용하는 프로그램 탭을 고르세요. 키 부분만 본인 발급키로 바꾸면 됩니다.

설정 파일을 엽니다 — ~/Library/Application Support/Claude/claude_desktop_config.json (Windows: %APPDATA%\Claude\). 메뉴 → Settings → Developer → Edit Config 버튼으로도 열립니다.

{
  "mcpServers": {
    "gov-data": {
      "command": "npx",
      "args": ["-y", "@leokim90/gov-data-mcp"],
      "env": {
        "DATA_GO_KR_SERVICE_KEY": "여기에_발급받은_키"
      }
    }
  }
}

붙여넣고 저장 → Claude Desktop 완전 종료(Cmd+Q) 후 재시작.

터미널에서 한 줄. --scope user면 그 컴퓨터 전체에서 사용됩니다.

claude mcp add gov-data --scope user \
  --env DATA_GO_KR_SERVICE_KEY=여기에_발급받은_키 \
  -- npx -y @leokim90/gov-data-mcp

확인: claude mcp list → gov-data ✔ Connected 보이면 성공.

Cursor·Windsurf·Cline 등은 Claude Desktop과 같은 JSON 포맷을 씁니다. 각 프로그램의 MCP 설정에 아래를 넣으세요.

{
  "mcpServers": {
    "gov-data": {
      "command": "npx",
      "args": ["-y", "@leokim90/gov-data-mcp"],
      "env": {
        "DATA_GO_KR_SERVICE_KEY": "여기에_발급받은_키"
      }
    }
  }
}

Cursor: Settings → MCP → Add · Windsurf: ~/.codeium/windsurf/mcp_config.json

3

동작 확인

  • Claude Desktop — 채팅창 좌하단 🔨(망치) 아이콘 클릭 → gov-data에 도구 6개가 보이면 정상
  • Claude Code — 새 세션에서 /mcp 입력 → gov-data ✓ connected
  • Cursor 등 — MCP 설정 화면에서 gov-data가 초록불(connected)
