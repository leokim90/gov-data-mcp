# docs 스크린샷 폴더

가이드에서 참조하는 스크린샷을 여기에 넣는다. 파일명을 아래와 맞춰 저장하면 가이드에 자동으로 표시된다.

| 파일명 | 캡처 내용 |
|--------|-----------|
| `key-data-go-kr.png` | data.go.kr 마이페이지 → 인증키 발급현황 (일반 인증키 값 위치) |
| `key-bizinfo.png` | 기업마당 마이페이지 → 오픈API 신청/관리 → 인증키 |
| `key-smes.png` | 중소벤처24 마이페이지 → Open API 관리 → API 토큰 |
| `desktop-edit-config.png` | Claude Desktop → Settings → Developer → Edit Config 버튼 |
| `desktop-tools.png` | Claude Desktop 채팅창 좌하단 🔨 아이콘 → gov-data 도구 6개 목록 |
| `code-mcp-list.png` | 터미널 `claude mcp list` 출력 (`gov-data ✔ Connected`) |

> PNG 권장, 가로 1200px 내외. 개인정보(실제 키 값 등)는 가린 뒤 캡처할 것.
> 스크린샷이 없으면 가이드의 이미지 자리에 깨진 아이콘만 보일 뿐 내용엔 지장 없다.
